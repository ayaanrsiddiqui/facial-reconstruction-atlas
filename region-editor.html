Face Region Editor

Drag points to line them up with the photo, then save back into the app.

Add a shape

Click Draw new shape, then click points on the photo to trace the region. Click Finish shape (or double-click) when done — need at least 3 points. For left/right regions (temple, periorbital, ear, cheek, etc.) you only need to draw one side — with Mirror left/right on, the other side is created and kept in sync automatically.

Selected shape

Drag the white handles to move a point. Right-click (or long-press) a handle to remove it. With Add point mode on, click along the outline to insert a new point there.
